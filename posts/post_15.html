title:JSON and BYTES; date:3 August 2026 - 15:29; class:; ~ I made my byte storage thing for dunge be able to convert json to bytes, very nice, although everything has to be a string to be able to say what type of value you're saving, like imagine if youd want to save a long, then you would have to type

{"entry": "<long> 10"}

or some other type, these are the types:
none (also without <>) is a normal string
int, i, i32, integer for ints
long, l, i64 for longs
byte, b, i8 for bytes
short, s, i16 for shorts
char, c, u16 for characters
float, f, f32 for floats
double, d, f64 for doubles

i chose mutliple strings per type so it's easier to use on the fly
