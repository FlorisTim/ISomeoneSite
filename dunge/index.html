What is dunge?
Dunge is a top-down dungeon crawler, the idea is that it's completely procedural, so every room is predictable according to specific formulas, and so is time, it has been a passion project for me since i was 15, i used to make it in scratch, but now i'm making it in processing in java

Things planned for DUNGE
I'm planning on making plants, ores, etc be procedurally generated using L-Systems, i made something like this before in scratch, the idea is that theres a byte array, where every even entry is an instruction and every odd entry is an argument (assuming the array starts at 0), and then by chaning every odd entry in the array i slightly mutate the plant, this would create slight variation and fits into some simulated evolution that might be added later on
