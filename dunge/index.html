Things made for DUNGE
From June to Aug 2026 i have created 2 DSL's, one for animation and one for enemy AI, both very easily debuggable and easy to understand after some use.

the animation DSL gets turned into bytecode, one of the neat features it has is that you can copy entire sections of code, and replace sections of them within copies, so for example animating a second arm does not require 2 sets of the same script but with the values flipped

the AI DSL is specifically was designed for readability, for example i turned scripts like this
ADD 5 5;
IFEQ result 10; ...
into scripts like this
IF 5 + 5 == 10
(
...
)
 basically letting the compiler pipeline transform the secondary script back into the primary, and using that to create the bytecode, furthermore i made a simple data system that turns json into chunks of 24 bytes, leaving out the types for extra compactness, it uses chains of blocks to store data, for example if i store the string "hello" and the value 5 the data would look like this
[ref1][hello][ref2][5]
and if you changed the string to a different size (ex. "hello world") it would become this
[ref1][hello (skip 2)][ref2][5][world]
making it skip the 5 chunk, this works very well and does not have the hasstle of needing to shuffle around everything in a file to just change one entry

I also made the world generation be based on a json that decides how noise is generated and under what conditions a structure should be placed, i used this same idea to make the walls of the dungeon connect based on where you are not based on the surrounding rooms.
