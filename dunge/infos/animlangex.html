types in bytes

00000000:0 // positive number
00000001:1 // negative number
00000010:2 // skip
00000011:3 // nothing
00000100:4 // nothing
00000101:5 // nothing
00000110:6 // function
00000111:7 // end statement

arguments are ALWAYS only bytes, variables or enums, and you can prefix them with a negative (-) to negate them. FYI variables and enums are translated into bytes in the compiler, they are purely for neat code

the SAVE and LOAD system only allow one state to be saved, when you save twice the first save is lost

byte keyword description arguments
0 "ORIGIN_X", sets the origin x (x)
1 "ORIGIN_Y", sets the origin y (y)
2 "SPEED", sets the animation speed (speed)
3 "SET_DIRECTION", sets the direction (direction)
4 "CHANGE_DIRECTION", changes the direction (amount)
5 "STEP", changes x and y into dir (amount)
6 "CHANGE_X", changes x (amount)
7 "CHANGE_Y", changes y (amount)
8 no opcode
9 "STAMP", stamps a sprite (sprite index)
10 "SET_DIRECTION-t1", sets direction based on sin (range, speed)
11 "SET_DIRECTION-t2", sets direction based on cos (range, speed)
12 "CHANGE_X-t1", changes x based on sin (range, speed)
13 "CHANGE_X-t2", changes x based on cos (range, speed)
14 "CHANGE_Y-t1", changes y based on sin (range, speed)
15 "CHANGE_Y-t2", changes y based on cos (range, speed)
16 "STEP-t1", changes x,y into dir based on sin (range, speed)
17 "STEP-t2", changes x,y into dir based on cos (range, speed)
18 "LOAD", loads the saved state no arguments
19 "SAVE" saves current state no arguments
20 "ORIGIN" sets the origin x and y (x, y)
21 "CHANGE_DIRECTION-t1", changes direction based on sin (range, speed)
22 "CHANGE_DIRECTION-t2" changes direction based on cos (range, speed)
23 no opcode
24 "STEP_SIDE", changes x and y into dir +90 (amount)
25 "IFSTATE", checks if a state is active (state)
26 "RETURN" adds its x, y to the output array no arguments

you can use comments by starting a line with //

//enums example
enum a b c;
//a = 0, b = 1, c = 2

//variable example
var a 50;
//a = 50;

you can do -enum or -var to negate the values, enums automatically assign positive numbers, variables only allow positive values

indexer this is defined by an opening and closing bracket like so

(
any code
)

if any previous statement is false, then it skips anything in brackets, if all statements are true, then it runs the code in the bracket and resets the skip value, making it true again, meaning a statement or multiple have to be true for the next indexer to not be skipped.

they're called indexers cus the compiler only saves the amt of bytes in the space using another index.
