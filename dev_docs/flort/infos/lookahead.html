["title"]Looking ahead[/] ["post spckbd"] ["title"]October 2026[/] So the current output contains a lot of Unknowns and ambiguous tokens. I solved these using the following techniques

A few arrays get initialized, for example an array fo custom types, it adds every token that is unknown and comes after the "class" token, now that token whenever encountered will be reclassified as a TypeIdentifier (if the token in question is unknown).
same for variables and methods, it does it in a slightly different way, but fundamentally the same.

this way a case like Box<Something<AnotherThing>> Will make the ambiguous last token (the ">>") turn into two closing brackets (instead of a right bit shift).
It does not tell what type variables are, or functions return, but it gives enough information to resolve all ambiguous cases. [/] ["back"]
