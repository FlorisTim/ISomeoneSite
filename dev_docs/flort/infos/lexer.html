["title"]Parser[/] ["post spckbd"] ["title"]October 2026[/] Splitting text like print(hello, world); Into elementary tokens like: print ( hello , world );
I did this by having 2 lists of characters, the normal characters (a-z, A-Z, 0-9 and _) and the syntax characters (plus minus brackets etc..)
while scrolling through an input string, it constructs a string by adding the character of the input string to it.

it switches modes depending on what character it sees (normal or syntax), and before it switches and appends the new character it emits the current string and clears it.

the config it gets also holds a character list of singular characters, so when it encounters a character like ")" it immediately emits a token.

Numbers are handled similarly, the config holds a number character list.
But there's an issue:
the character for field access is the same character as the decimal point
I solved this by looking ahead and seeing if the current string
if '.' is already a valid number (for example 1.) or concatenated with the next character would be a valid number (for example .1), otherwise its a field access symbol.

Sometimes, however there are 'ambiguous' cases. for example in this code: Box<Something<AnotherThing>> it ends with ">>", this could either be 2 closing brackets, or a right bit shift operator
so it gets parsed as ambiguous, maintaining the 2 possibilities.
