the generator uses the following structure

{
  "generators": \[
    {
      "name": "basic",
      "smoothing": 5,
      "circular_smoothing": true,
      "contrast": 2,
      "midpoint": 0.5,
      "chunking": 10,
      "handler": \[
        "CHUNK",
        "SMOOTH",
        "MOD",
        "CONTRAST",
        "ABSOLUTE",
        "MOD"
      \]
    }
  \],
  "features": \[
    {
      "name": "rare station",
      "conditions": \[
        {
          "negate": false,
          "type": "NOISE_here",
          "test": "basic",
          "min": 0.2,
          "max": 0.4
        },
        {
          "negate": false,
          "type": "FEATURE_cross",
          "test": "rare station",
          "min": 1,
          "max": 2
        }
      \]
    }
  \]
}

Generators structure

this will explain how to create an entry in the "generators" array

keys and values

key value description
name its name where it gets referenced by
smoothing by how much its noise map should be smoothed
circular_smoothing if the smoothing patterns is circular (true) or sqaure (false)
contrast by how much the values of the noise map get amplified
midpoint what should be considered "0" for the contrast function
chunking how much chunks of the same values should appear in the noise map
handler the order of when these actions should be applied to the map

handler keywords

\[
 "CHUNK",
 "SMOOTH",
 "MOD",
 "CONTRAST",
 "ABSOLUTE",
 "MOD"
\]

these are able to be used in any order you'd like, or even used multiple times or not at all, the "CHUNK" and "SMOOTH" keywords require the generator to generate other tiles on its map, potentially slowing it down if used more than once.

Features structure

keys and values

there are only 2 keys, those are

  • name
  • conditions

"name" is the name its referenced by.

Condition structure

key value description
negate if the conditions output (true or false) should be negated
type what type of condition it is
test what it will be testing for
min the minimum requirement for that test
max the maximum requirement for that test

it will return true if the tests output is within the min and max range, the result will be flipped to false if negate is set to true.

Condition types

type meaning expected test value return value
NOISE_here will give the value at its position on the noise map a generator name a double
NOISE_cross will give the average of all values in a cross shape around it a generator name a double
NOISE_square will give the average of all values in a square shape around it a generator name a double
FEATURE_cross will check for each neighbour in a cross if it contains a feature a feature name an int
FEATURE_square will check for each neighbour in a square if it contains a feature a feature name an int

if all conditions return true then the feature will be added to the room
